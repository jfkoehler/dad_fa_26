# Data and Design with Python

**LMTH 2080 · Fall 2026**
**Eugene Lang College of Liberal Arts · The New School**
**Mondays, 9:00–11:40 AM**

Course materials for **Data and Design with Python**.

This course introduces Python through questions that data can help us investigate, explain, and address. We will work with data, visualization, APIs, interactive applications, machine learning, and pretrained models, with an emphasis on designing computational work that is useful to others.

## Course Materials

* `syllabus.tex` — course syllabus
* `dad.sty` — shared LaTeX style
* `day01/` — Useful Data
* `assignments/` — course assignments

Additional materials will be added throughout the semester.

## Course Arc

**question → data → computation → representation → interaction → model → application**

The course culminates in an interactive Streamlit application built around a pretrained model from the Hugging Face Model Hub.
